# 세션 D — 라벨 규칙 역추적 노트

목표: 단계 3·4·5·6 라벨을 만든 결정 규칙을 센서 컬럼에서 역추적 → 인과적 규칙 피처(`rules.py`) → 공통 검증(cv.py)으로 평가.
이미 확인된 것(사령탑): 2단계 시작 = `meas_t1 >= 45` 첫 행 (97/97 정확).

(아래는 발견할 때마다 추가)

## [진행 1] 스캔 도구와 1차 관찰
- `scan.py`: 후보 피처 147개(원값, 5~300초 차분, 누적, 가스 이동평균 등)에 대해 "onset 이전 행 최댓값 < θ ≤ onset 행 값" 구간을 가장 많이 관통하는 θ 탐색.
- **3단계**: 단일 임계 규칙 없음. 전체 최고가 16/97 (`meas_p` 60초 차분), 그룹별로도 bat3/cc28에서 `t2>=67.2` 11/16 정도가 최고. → 센서 단일 임계로는 재현 불가.
- **4단계**: 전압 급락 이벤트. `meas_v`의 5초 차분 <= -0.56 (3단계 이후 첫 행) → 정확 63/94, 규칙이 1행 늦음(+1) 19/94.
  +1인 19개는 **라벨이 바뀐 행에서 센서에 아무 변화가 없고 다음 행에서 전압이 급락**한다 (E_1915: 4.145→(라벨 4) 4.145→0.000).
  ⇒ 라벨 경계가 센서 이벤트보다 1행(5초) 빠른 경우가 약 20% 존재. 인과적으로는 이 행을 맞출 수 없다 (라벨 시각과 센서 시각의 어긋남으로 보임).
- `v < 2.5` 절대 임계: 정확 55, +1 28, 그 외 11. 급락 규칙보다 조금 나쁨. bat3/cc280/tr1(전압이 서서히 내려가는 대형 셀)에서는 v<2.5가 맞음.

## [진행 2] 4단계 규칙 조합, 3단계 압력 단서
- 4단계: `A = dv5 <= -0.56`, `B = v < 2.5`. **A|B (게이트 불필요, 실험 시작부터 첫 발화)**: 정확 66/94, +1(라벨이 1행 빠름) 19, -1 2, 그 외 7
  (E_23fc -133행·E_e72c -255행: 과충전(tr2) 중 전압 요동으로 조기 발화 / E_7528 +74행: 실제 onset은 3.635→3.47의 약한 하강(v/vmax≈0.833) / E_6193 -10행: 일시적 급락 후 회복 / E_019e -4, E_5736 -6, E_3849 +2).
  4단계가 없는 3→5 실험 3개(E_1ea0, E_31e1, E_e5bc)는 이 이벤트가 5단계 시작 행(0~+1)에서 발화 → "전압 이벤트 시점에 5단계 조건이 이미 참이면 4를 건너뜀"으로 해석.
- 3단계: 허용 오차(+1행)를 줘도 단일 임계 규칙 최고가 23/97 (`meas_p` 5초 차분 >= 0.39). 그룹별로도 없음.
  다만 압력 시계열을 보면 **3단계 시작 0~3행 뒤에 압력이 오르기 시작**하는 실험이 많다 (bat3/cc28, bat2/cc73: E_5379 +3행, E_9cd7 +2, E_d164 +2, E_b096 +1, E_6331/E_a8bb/E_aac8 +1에 압력 급등).
  ⇒ 3단계는 "가스 발생/스웰링 시작(압력 상승 시작)"류 이벤트로 보이고, 라벨이 센서 이벤트보다 0~3행 앞선다. 센서로 인과적으로 정확히 재현 불가.
- 가설: 라벨은 원본(더 촘촘하거나 다른 로거 시계) 기준 이벤트 시각으로 만들었고, 제공 CSV의 전압·압력 채널은 t1 채널 대비 0~15초 늦게 정렬되어 있다 (2단계 t1>=45만 100% 정확한 이유).

## [진행 3] 6단계 = `meas_t1_plus_t2`(t1+t2) 전체 최댓값 시점 (비인과 규칙)
- 6단계 시작 행 vs 실험 전체 argmax(t1+t2): **정확 55/93, 라벨이 1행 뒤(-1) 33, ±2행 이내 90/93**. argmax(t1)만으로는 정확 31, argmax(t2) 21 → 합(t1+t2)이 기준. CSV에 `meas_t1_plus_t2` 컬럼이 따로 있는 이유로 보인다.
- 대부분의 실험이 6단계 시작 후 약 20행(95~100초)에서 끝난다 (피크 후 100초에서 잘라낸 것으로 보임).
- 인과적으로는 "지금까지의 t1+t2 최댓값에서 내려왔다"로만 근사 가능 (피크는 다음 행을 봐야 알 수 있음).
- 5단계(허용 +1행): bat2/tr1은 `v == 0` 15/15, bat2/tr2 `v <= 0.005` 8/10, bat1은 `v <= 1.355` 20/31, bat3/tr2 `thermal_t >= 178.5` 6/7, bat3/tr1은 t1 5초 상승 >= 4.9 (≈1℃/s) 11/26.

## [진행 4] 비인과 정규화 피처·5단계 그룹별 규칙
- 실험 전체 최댓값으로 정규화한 값(S/Smax, (S-S0)/(Smax-S0), t/t_peak 등)으로 3·4·5단계를 설명하는 규칙은 없음 (최고 14~17/97). → 3~5단계는 비율 규칙 아님.
- 5단계 (4단계 이벤트 이후 첫 발화, 5초 원본 기준):
  - bat1: `v <= 1.355` 정확 20/31 (±2행 21). 2차 전압 강하(`dv<=-0.4`)도 20/31. 나머지는 4단계에서 이미 전압이 낮아 온도/시간 기준으로 보임.
  - bat2: `v == 0` 정확 20/25, +1 2 (±2행 22). 5단계가 없는 4→6 실험 7개는 v==0이 6단계(피크)와 같은 시점 → "피크가 먼저/동시에 오면 5를 건너뜀".
  - bat3/cc28: t1 상승 >= 4.2℃/5초(≈0.84℃/s): 16개 전부 ±2행 (정확 6, +1 5). 전압은 4단계에서 이미 0.
  - bat3/cc280: 뚜렷한 규칙 없음 (`thermal_t >= 170` ±2행 9/17).

## [진행 5] 코드와 순수 규칙 점수
- `rules.py`: `rule_features(frame, t3=55) -> DataFrame(r_* 30개)`, `rule_predict(frame, t3) -> Series`, `self_test(frame)`.
  Test 3,451행 7ms. 행 섞기 / 실험별 분리 / 앞 60%만: pool·evalp·test 모두 완전 일치(True).
  Test 11개 실험 전부에서 t1>=45, t1>=50, 전압 급락, 5단계 규칙, 피크 통과가 발화 (튜닝 아님, 실행 확인).
- 6단계 인과 근사 `전압 이벤트 이후 & cummax(t1+t2)>=300 & (t1+t2) < cummax-5`: 원본 5초 기준 정확 16, +1 32, +2 9, 조기 11, 3행 이상 늦음 18, 미발화 4 (93개 중). 급상승 구간의 국소 하강 때문에 조기 발화가 생김.
- **순수 규칙 예측 (`run_rules.py --mode rule_only`, 5-fold×3, t3만 학습 fold에서 선택)**: CV 0.8476 [0.820, 0.871], long 0.663 / short 0.869, per-class [1.0, .723, .838, .807, .842, .875]. vs tab_all_pool -0.048.

## [진행 7] 추가 확인

## 최종 정리 (세션 D)
- 규칙 정확도: 2단계 t1>=45 (97/97) / 3단계 재현 불가 (t1>=50 필요조건 + 압력 상승 시작 직전) / 4단계 전압 급락 (정확 66, ±1행 87/94) / 5단계 배터리 종류별 (bat1 20/31, bat2 20/25, bat3·cc28 ±2행 16/16, bat3·cc280 불명확) / 6단계 argmax(t1+t2) (정확 55, ±1행 90/93, 비인과).
- 권장: `rules.rule_features`의 30개 피처를 테이블 모델에 추가. 최고 `rules_tab_nocum_r3` CV 0.9074 (기준 tab_all_nocum_r3 0.9040 대비 +0.0034, p .85 → 채택 기준 0.9에는 못 미침. tab_all_pool 대비는 +0.0076 p .94 / 같은 설정 직접 비교 +0.0046 p .95).
- 주의: rules.py의 상수 임계값(−0.56, 2.5, 1.355, 0.84℃/s, 170, 300/5)은 라벨 있는 97개 실험 전체에서 정했다 (fold 안에서 다시 고르지 않음, t3만 fold 내 선택). 상수 몇 개라 영향은 작겠지만 CV가 약간 낙관적일 수 있다.
- 남은 의문: 3단계의 두 번째 조건, bat3·cc280의 5단계 조건, 라벨이 센서 이벤트보다 0~3행 앞서는 이유(채널 간 시계 어긋남 추정).
