# 세션 D — 라벨 규칙 역추적 노트

목표: 단계 3·4·5·6 라벨을 만든 결정 규칙을 센서 컬럼에서 역추적 → 인과적 규칙 피처(`rules.py`) → 공통 검증(cv.py)으로 평가.
이미 확인된 것(사령탑): 2단계 시작 = `meas_t1 >= 45` 첫 행 (97/97 정확).

(아래는 발견할 때마다 추가)

## [진행 1] 스캔 도구와 1차 관찰
- `scan.py`: 후보 피처 147개(원값, 5~300초 차분, 누적, 가스 이동평균 등)에 대해 "onset 이전 행 최댓값 < θ ≤ onset 행 값" 구간을 가장 많이 관통하는 θ 탐색.
- **3단계**: 단일 임계 규칙 없음. 전체 최고가 16/97 (`meas_p` 60초 차분), 그룹별로도 bat3/cc28에서 `t2>=67.2` 11/16 정도가 최고. → 센서 단일 임계로는 재현 불가.
- **4단계**: 전압 급락 이벤트. `meas_v`의 5초 차분 <= -0.56 (3단계 이후 첫 행) → 정확 63/94, 규칙이 1행 늦음(+1) 19/94.
  +1인 19개는 **라벨이 바뀐 행에서 센서에 아무 변화가 없고 다음 행에서 전압이 급락**한다 (E_1915: 4.145→(라벨 4) 4.145→0.000).
  ⇒ 라벨 경계가 센서 이벤트보다 1행(5초) 빠른 경우가 약 20% 존재. 인과적으로는 이 행을 맞출 수 없다 (라벨 시각과 센서 시각의 어긋남으로 보임).
- `v < 2.5` 절대 임계: 정확 55, +1 28, 그 외 11. 급락 규칙보다 조금 나쁨. bat3/cc280/tr1(전압이 서서히 내려가는 대형 셀)에서는 v<2.5가 맞음.
